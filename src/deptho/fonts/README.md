# Bundled fonts

Used only to draw the fill gap card's PNG (`deptho/card.py`), so it looks the same on every
machine. Both are unmodified and licensed under the SIL Open Font License 1.1, which allows
bundling them with software; each licence is next to its font. They aren't sold separately.

| file | font | source |
|---|---|---|
| `SpaceGrotesk-Variable.ttf` | Space Grotesk 2.000 (variable, weights 300-700) | github.com/floriankarsten/space-grotesk, `fonts/ttf/SpaceGrotesk[wght].ttf` at 03507d024a01282884232081fc6011c09ff4e849 |
| `JetBrainsMono-Regular.ttf` | JetBrains Mono 2.305 Regular | github.com/JetBrains/JetBrainsMono, `fonts/ttf/JetBrainsMono-Regular.ttf` at 19371302b95d218af43299bce79ddbddd0bc364d |

Those are the commits Google Fonts builds from (google/fonts `ofl/spacegrotesk`, `ofl/jetbrainsmono`).
